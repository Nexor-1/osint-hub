## OSINT Hub 1.0.0

Первый выпуск. Десктопное приложение для Windows 10/11 x64, которое объединяет ExifTool, PhoneInfoga, Holehe, SpiderFoot и Sherlock в одном интерфейсе.

### Установка
1. Скачайте `OSINTHub-Setup-1.0.0.exe`. При желании сверьте SHA-256 с файлом `SHA256SUMS.txt`.
2. Запустите установщик. Права администратора не нужны, Python ставить не надо.
3. Установщик создаёт ярлык на рабочем столе и в «Пуске», а также деинсталлятор.

Установщик **не подписан** цифровой подписью, поэтому Windows SmartScreen может показать предупреждение («Подробнее» → «Выполнить в любом случае»). Если хотите, соберите приложение сами из исходников: `build.bat` (см. README).
